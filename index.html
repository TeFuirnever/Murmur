FAQ

Frequently Asked Questions

macOS says 'cannot verify developer' and won't open the app? +

Right-click the Murmur app → select 'Open' → click 'Open' again. This is macOS's security prompt for unsigned apps. Murmur is free open-source software without a paid developer certificate.

First launch is slow — what's being downloaded? +

On first launch, Murmur downloads the FunASR speech recognition model (~1GB). Once downloaded, it's cached locally and won't need downloading again.

How do I configure AI text optimization? +

Open Settings → enter your API Key in the AI section → select a model provider (DeepSeek, Qwen, Ollama, etc.) → save. AI optimization is optional — speech recognition works without it.

Where is my data stored? +

All data is stored locally in SQLite: macOS ~/Library/Application Support/murmur/transcriptions.db, Windows %APPDATA%/murmur/transcriptions.db. Nothing is uploaded to any server.

What export formats are supported? +

Export to TXT, SRT (subtitles), VTT (Web subtitles), Markdown, and DOCX (Word document).

What is the global hotkey? +

Default: Cmd+Shift+Space (macOS) / Ctrl+Shift+Space (Windows/Linux). Press to start recording, press again to stop and auto-paste text at cursor.

Do I need ffmpeg installed? +

Usually no. Since v1.0.0, Murmur uses Python librosa/soundfile for audio conversion. ffmpeg is only needed as a fallback for mp3/m4a files when librosa is unavailable. WAV/FLAC always work without ffmpeg.

Which platforms are supported? +

macOS (Apple Silicon arm64) and Windows. Linux builds are not yet available. On macOS, the app is unsigned — right-click → Open on first launch.
