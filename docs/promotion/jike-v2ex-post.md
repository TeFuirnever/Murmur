```
[分享创造] Murmur — 开源本地中文语音输入工具（FunASR + Electron）

做了一个开源的桌面语音输入工具，想分享给有同样需求的开发者。

## 解决什么问题

市面上的语音输入方案：
- macOS 原生听写：中文精度一般，依赖联网
- 讯飞/搜狗：精度高，但语音数据必须上传云端
- Whisper Desktop：偏英文，中文口头禅全保留
- Wispr Flow：效果好，但 $10/月

我想要的是：中文精度高 + 完全本地 + 开源免费。

## 技术方案

- 语音识别：阿里 FunASR Paraformer-large（本地推理，不上传）
- AI 润色：兼容 OpenAI API 的任意模型（DeepSeek / 通义 / 智谱 / Ollama 等 11+ 个）
- 桌面框架：Electron 36 + React 19
- 数据存储：SQLite（better-sqlite3 + safeStorage 加密）

AI 是可选的——不配 API Key 也能用，只是不做润色。配上本地 Ollama 连 API Key 都不用。

## 特性

- Cmd+Shift+Space 全局热键，说完自动粘贴到光标
- 音频文件导入转录（wav/mp3/m4a/flac）
- FTS5 全文搜索 + 导出（TXT/SRT/Markdown/DOCX）
- TypeScript 严格模式，652 测试，95% 覆盖率
- 中英双语 UI

## 安装

Windows: winget install TeFuirnever.Murmur
```

```
## 你有没有这些瞬间

- 写周报，脑子里有想法但打字跟不上思路
- 回复长消息，打了一大段发现逻辑混乱
- 开会录音，事后整理纪要花了一小时
- 做视频字幕，一句一句听写

这些场景，本质上都是"打字速度跟不上思考速度"。

## Murmur 怎么解决

Murmur 是一个桌面语音输入工具。按下 Cmd+Shift+Space，开始说话，说完文字就出现在光标位置。

三个关键设计：

**1. 本地识别，隐私无忧**
用的是阿里开源的 FunASR 模型，所有识别在本地完成。你的语音数据不会上传任何服务器。对隐私敏感场景（医疗、法律、商业机密）特别重要。

**2. AI 润色，去口头禅**
说话难免有"然后...然后..."、"那个那个"。Murmur 接入 AI 模型自动修掉这些，还能整理段落格式。支持 DeepSeek（注册送免费额度）、通义千问、智谱、Ollama 等。

**3. 音频文件转录**
拖入一个会议录音，自动转成文字。导出 SRT 直接做字幕，导出 Markdown 直接做纪要。
```
