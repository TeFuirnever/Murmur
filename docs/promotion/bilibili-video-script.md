# B站 / 抖音 视频脚本

> 用途：视频演示是语音工具最高转化率的推广方式（"必须看到效果"）。
> 应用 skill：huashu-video-outline（大纲策略）+ huashu-script-polish（口语化审校）。
> 平台差异：B站偏 3-5 分钟教程，抖音偏 30-60 秒种草。

---

## 方案 A：B站 教程型（推荐首发，转化率最高）

**标题候选（应用 5 种强对比公式）：**

1. 🏆 `免费开源 vs 讯飞/Whisper，这个语音输入工具赢在哪？`（价格对比）
2. `说话比打字快 3 倍：Murmur 本地语音输入实测`（时间对比）
3. `1 个工具 vs 10 个 App：我的语音输入终极方案`（数量对比）
4. `macOS 原生听写太难用？我找到了更好的选择`（强弱对比）

**推荐标题**：方案 1 —— 价格对比在 B站最吸引点击（免费是最大钩子）

**封面建议**（< 10万粉用结果展示封面）：

- 左半：Murmur 界面截图 + "免费 开源 本地"
- 右半：竞品 Logo 矩阵（讯飞/Whisper/Wispr）+ "收费 / 上传 / 英文"
- 大字标题："语音输入终极对比"

**时长**：⏱️ 4-5 分钟

### 完整脚本（口语化审校后）

> 应用 huashu-script-polish 的三遍审校：去书面腔、加口语词、适合说出来。

```
【0-3s 钩子】
（录屏：对着电脑说话，文字飞速出现）
说话就能打字。而且——完全免费，完全本地。

【3-8s 标题】
（切标题卡）
这个工具叫 Murmur。今天花 4 分钟，告诉你它值不值得装。

【8-20s 痛点】
（录屏：打字慢的尴尬）
你有没有这样——脑子里想法一堆，打字就是跟不上。
Mac 自带听写，中文效果一般。
讯飞要上传你的语音数据。
Whisper 偏英文，中文口头禅全保留。

【20-40s 定位】
（界面展示）
Murmur 是一个开源的语音输入工具。
核心就一句话——按快捷键，说话，文字出现在光标。
就这样。没了。

【40-90s 演示1：实时输入】 ⭐ 最重要
（切全屏录屏）
来，实测。
我现在对着电脑说话，你看——
（说话的同时文字出现）
文字实时出来了。
说完，自动粘贴到光标位置。
不用切换窗口，不用复制粘贴。

【90-140s 演示2：AI润色】
但说话难免有口头禅对吧。
我给你模仿一下：
"那个那个，我觉得吧，这个功能其实吧，挺好用的。"
（切润色前后对比）
Murmur 能接 AI 模型，自动修掉这些。
你看，左边是原始转录，右边是润色后。
干净多了。
支持的模型有十几个——DeepSeek 注册送免费额度，通义、智谱、Ollama 本地模型都行。

【140-180s 演示3：文件转录】
还能导入音频文件。
（拖入文件）
比如这个会议录音。等几秒——
（展示转录结果）
全文出来了。
直接导出 SRT 做字幕，或者导出 Markdown 做纪要。

【180-220s 对比】
（切对比表）
和其他工具对比一下。
中文精度——Murmur 和讯飞最好。
本地运行——Murmur、Mac 听写、Whisper 都行，讯飞不行。
AI 润色——只有 Murmur 有。
开源免费——Murmur 和 Whisper。
综合下来，Murmur 全占。

【220-250s 隐私】
最后说一个点。
Murmur 完全本地运行。
你的语音数据，永远不离开你的电脑。
对隐私敏感的场景——医疗、法律、商业——这个特别重要。

【250-280s 结尾】
安装很简单。
Mac 一行命令：brew install --cask murmur。
Windows：winget install TeFuirnever.Murmur。
开源地址在简介，Apache 协议。
觉得有用的话，点个赞，给个 Star。
下期见。
```

## 备注：为什么视频比图文重要

语音输入工具的推广有个特殊挑战：**用户必须"看到效果"才会相信**。

文字描述"说话就能打字"不够直观——用户会想"真的假的？识别准吗？延迟多少？"

视频演示直接回答这些问题。这也是 strategic-plan-gap-analysis.md 里 T2-2（竞品定位文档 + 演示）的核心建议。
