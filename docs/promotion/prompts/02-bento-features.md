### Visual Design Direction

- Bento grid: varied card sizes (1 large + 7 medium, or 2 large + 6 medium)
- Each card has: icon illustration + feature name + one-line description
- Apple-inspired aesthetic: rounded corners (16px), subtle shadows, generous whitespace
- Flat vector icons — no realistic imagery
- Consistent icon style across all cards (same line weight, same color treatment)

### Color Palette

- Background: off-white (#F5F5F7) — Apple-like
- Card backgrounds: pure white (#FFFFFF) with subtle shadow
- Accent: Apple blue (#0071e3) for highlights and icons
- Secondary accents: soft pastels for category differentiation
- Text: near-black (#1D1D1F) for headings, gray (#86868B) for descriptions

### Aspect Ratio

16:9 landscape (primary use: README/blog)
Also works cropped to 1:1 for social media

### Language

Bilingual: Chinese primary (larger), English secondary (smaller, gray)
