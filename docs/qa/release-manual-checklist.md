# Murmur 发版人工验收清单（Release Manual Checklist）

> 来源：Spec #266 T02（五级测试体系补全）。以下场景属于 L5 验收层——**任何 mock 层都无法覆盖**（真实 OS 音频栈、真实模型体积、真实 TLS/账单、真实钥匙串弹窗），自动化门禁（`pnpm ci:check`、发布 workflow 五类门禁）绿不等于这些链路可用。
>
> **执行规则**：每次打 `v*` 发版 tag 之前，逐项勾选；macOS 与 Windows 各执行一遍（标注"单平台"的除外）。任何一项失败 → 停止发版，开 bug 票。结果（勾选 + 关键数值截图/文本）贴到当次 release issue 归档。
>
> 环境基线：干净用户目录的机器（或新建系统用户）+ 一台日常使用机器；两台都跑 §1–§5。
