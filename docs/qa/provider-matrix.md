# Murmur LLM 供应商兼容走查单（Provider Matrix）

> 来源：Spec #266 T18/#295。目的：Murmur 支持自定义 OpenAI 兼容供应商，"能用"依赖真实网络行为（TLS、鉴权、流式差异、错误返回格式），无法 mock 覆盖。本走查单在**每次发版前**执行一遍，结果归档到 release issue（发版清单 §0.2 引用本单）。
>
> 执行环境：真实网络（无代理/有代理各跑一轮，如当季发版涉及网络栈变更）。

## 走查矩阵

对以下三家代表供应商，逐列完成：

| 供应商      | Base URL（示例）              | 模型（示例）    | 备注                       |
| ----------- | ----------------------------- | --------------- | -------------------------- |
| OpenAI      | `https://api.openai.com/v1`   | `gpt-4o-mini`   | 官方参考实现               |
| DeepSeek    | `https://api.deepseek.com/v1` | `deepseek-chat` | 国内直连、价格敏感用户主力 |
| 本地 Ollama | `http://localhost:11434/v1`   | `qwen2.5:7b`    | 无 key 场景、离线用户      |

每家执行：

| #   | 场景                | 操作                                     | 通过判据                                                           | OpenAI | DeepSeek | Ollama |
| --- | ------------------- | ---------------------------------------- | ------------------------------------------------------------------ | ------ | -------- | ------ |
| 1   | 配置保存            | 在 AI 配置页填入 Base URL / Key / 模型名 | 保存成功，重进设置页回显一致                                       | ☐      | ☐        | ☐      |
| 2   | 「测试配置」        | 点击测试连接按钮                         | 明确的成功/失败提示；错误 key 时提示可懂（区分鉴权失败与网络失败） | ☐      | ☐        | ☐      |
| 3   | 实时录音 × 自动模式 | default_mode=auto，录一句短文本          | 润色结果返回并上屏；短文本走 optimize                              | ☐      | ☐        | ☐      |
| 4   | 文件导入 × 自动模式 | 导入 >150 字长音频，自动润色             | 长文本走 optimize_long，结果上屏                                   | ☐      | ☐        | ☐      |
| 5   | 模板模式            | 切换到某一模板模式（如「校对」）再转写   | 按所选模板输出，无串模板                                           | ☐      | ☐        | ☐      |
| 6   | 关闭 AI             | default_mode=off                         | 原文直接上屏，无 AI 请求发出                                       | ☐      | ☐        | ☐      |
| 7   | 错误路径            | 填错 key / 欠费账号后触发润色            | 错误提示可懂、原文不被破坏、无崩溃                                 | ☐      | ☐        | ☐      |
| 8   | 超时路径            | （可选）用不可达 Base URL 触发           | 按超时预算给出明确失败提示，UI 不假死                              | ☐      | ☐        | ☐      |
