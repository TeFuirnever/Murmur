常见问题

常见问题

macOS 提示「无法验证开发者」无法打开？ +

右键点击 Murmur 应用 → 选择「打开」→ 再次点击「打开」。这是 macOS 对未签名应用的安全提示，Murmur 是开源免费软件。

首次启动很慢，需要下载什么？ +

首次启动需要下载 FunASR 语音识别模型（约 1GB），下载后缓存在本地，后续无需重复下载。

如何配置 AI 文本优化？ +

打开设置 → AI 配置区域 → 填入 API Key → 选择模型提供商（DeepSeek、通义、Ollama 等）→ 保存。AI 优化是可选功能，不配置也可使用语音识别。

数据存储在哪里？ +

所有数据存储在本地 SQLite 数据库中，macOS: ~/Library/Application Support/murmur/，Windows: %APPDATA%/murmur/。不上传任何服务器。

支持哪些导出格式？ +

支持导出为 TXT、SRT（字幕）、VTT（Web 字幕）、Markdown、DOCX（Word 文档）。

全局热键是什么？ +

默认热键：Cmd+Shift+Space（macOS）/ Ctrl+Shift+Space（Windows/Linux）。按一次开始录音，再按一次停止并自动粘贴到光标。
